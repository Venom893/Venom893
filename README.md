## ⚡ `whoami`

I'm an **Electrical Engineering graduate** fascinated by what happens between a circuit idea and actual silicon.

My interests sit at the intersection of:

```text
Transistor-Level Circuits
        ↓
Analog / Mixed-Signal Design
        ↓
RTL & Digital Logic
        ↓
Verification & Simulation
        ↓
Synthesis
        ↓
Physical Design
        ↓
GDSII
        ↓
Silicon
```

I enjoy going beyond simply making something *work* — I like understanding **why** it works, how it can be modeled and verified, and how an RTL or circuit concept eventually becomes something physically implementable.

> 🧠 Think → Design → Simulate → Verify → Implement → Learn

## 🚀 PROJECTS I'VE BEEN BUILDING

<details>
<summary><b>🔋 Low-Power MAC — RTL-to-GDSII</b></summary>

<br>

A 32-bit MAC/accumulator taken through an RTL-to-GDSII implementation flow.

**What I worked with:**

- SystemVerilog RTL design
- Synthesis using Yosys
- Physical implementation
- Timing analysis
- Clock-tree analysis
- Power / physical analysis
- DRC & LVS verification

**Reported implementation results:**

```text
Clock        → 100 MHz
Area         → 5,062 µm²
Utilization  → 16%
Power        → 0.864 mW
DRC          → 0 violations
LVS          → 431 / 431 matched
```

<summary><b>⚡ GGNMOS ESD Protection Cell</b></summary>

<br>

A transistor-level ESD protection design explored using a **90nm gpdk090 PDK**, with SPICE/Spectre simulation and behavioral modeling.

**Explored:**

- Gate-Grounded NMOS (GGNMOS)
- ESD protection
- SPICE simulation
- Spectre transient analysis

- Snapback characterization
- HBM transient performance
- PDK/model debugging

**Key extracted characteristics:**

```text
Trigger voltage (Vt1) → 9.0 V @ 3.98 mA
Holding voltage (Vh)   → 5.35 V @ 20.4 mA
HBM stress             → 2 kV
```
